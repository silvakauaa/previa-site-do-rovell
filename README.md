# previa-site-do-rovell

Prévia do site de Rovell Marinho, personal trainer e atleta de fisiculturismo
(Campestre do Maranhão – MA).

Site estático: `index.html`, `styles.css`, `script.js` e a pasta `assets/`.
Não tem build. Para publicar no Netlify, basta apontar para a raiz do repositório.

Antes de usar um domínio próprio, trocar `https://www.SEU-DOMINIO.com.br/` em
`index.html`, `robots.txt` e `sitemap.xml`.
